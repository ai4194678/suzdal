# 🌿 ВПИСАТЬСЯ В СУЗДАЛЬ

### Найди своё место в городе, где хочется остаться подольше

**«Вписаться в Суздаль»** — интерактивный сервис подбора жилья для путешественников. Он помогает найти подходящий вариант проживания в зависимости от бюджета и предпочтений.

Суздальский вайб — бесценен. А вот ночлег вполне можно подобрать по бюджету!

---

## 🏡 О проекте

Планируешь поездку в Суздаль, но не знаешь, сколько придётся потратить на проживание?

Сервис поможет разобраться с предложениями на рынке аренды жилья и подобрать варианты, которые соответствуют твоим финансовым возможностям.

В основе проекта — база объявлений об аренде жилья с платформы Авито.

## ✨ Возможности

- **Подбор по бюджету:** укажи сумму, которую готов потратить на одну ночь.
- **Географический поиск:** выбирай жильё в Суздале или в ближайших населённых пунктах.
- **Фильтрация предложений:** смотри варианты, которые вписываются в твой бюджет.
- **Сортировка:** сравнивай жильё по стоимости, площади и другим доступным характеристикам.
- **Фотогалерея:** знакомься с интерьерами и выбирай подходящий вариант.
- **Избранное:** сохраняй понравившиеся предложения.
- **Переход к объявлению:** изучай подробности и уточняй условия проживания на Авито.

## 📍 География проекта

В базе представлены объявления из следующих населённых пунктов:

- Суздаль;
- посёлок Новый;
- село Сельцо;
- село Ивановское.

## 📊 Данные

Для работы сервиса используется CSV-выгрузка из 111 объявлений об аренде жилья.

Источники данных: объявления платформы Авито.

**Важно:** цены представлены по данным выгрузки для двух гостей на период с 21 по 22 ноября 2026 года. Они не гарантируют актуальную стоимость или наличие свободных дат. Итоговые условия проживания необходимо уточнять в исходном объявлении.

## 🚀 Запуск проекта

Проект рассчитан на работу без отдельного сервера и может быть опубликован с помощью GitHub Pages.

Для локального запуска:
1. Склонируй репозиторий.
2. Открой файл `index.html` в браузере.

Для публикации через GitHub Pages:
1. Открой Settings в репозитории.
2. Перейди в раздел Pages.
3. Выбери `Deploy from a branch`.
4. Укажи ветку `main` и папку `/ (root)`.
5. Нажми Save.
